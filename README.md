# Studio Catalogue

Retouche automatique et gratuite de photos d'objets (catalogues de vente, lots), entièrement dans le navigateur. Aucune photo n'est envoyée sur un serveur.

## Ce que fait l'appli

- Remplace le fond uni par du blanc pur, y compris dans les ajours (anses, pieds de meuble)
- Corrige la dominante de couleur, le vignettage et l'exposition
- Redresse l'objet (jusqu'à 12°), le recadre et le centre avec une marge régulière
- Ajoute une ombre de pose douce et de la netteté
- Exporte toutes les photos d'un coup en ZIP (JPEG ou PNG transparent), avec le nom d'origine ou une numérotation « Lot-001 »

## Utilisation

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main` pour l'utiliser en ligne.

## Limites

- Fonctionne au mieux sur un fond uni (drap, papier, mur clair)
- Les photos HEIC doivent être converties en JPEG, sauf sur Safari
